# MNIST Handwritten Digit Classification

## Overview
Implemented a neural network from scratch using Python and NumPy to classify handwritten digits from the MNIST dataset. Developed a second implementation using TensorFlow/Keras to compare performance.

## Implementation
- Forward propagation
- Backpropagation
- Gradient descent
- TensorFlow/Keras comparison

## Results
| Model | Accuracy |
|---|---|
| NumPy from scratch | 98.10% |
| TensorFlow/Keras | 97.86% |

## Evaluation
Compared model accuracy, loss, and execution time.
